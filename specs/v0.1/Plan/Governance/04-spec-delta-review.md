# Spec Delta Review (obligatoire chaque sprint)

## Objectif

Rendre visibles les ecarts entre implementation et specification, puis decider explicitement.

## Template de revue

1. Sprint.
2. Requirements couvertes.
3. Ecart(s) detecte(s):
   - reference spec,
   - comportement observe,
   - impact.
4. Decision:
   - corriger maintenant,
   - accepter provisoirement,
   - re-planifier.
5. Date + owner.

## Regles

- Toute deviation `MUST` doit avoir une decision explicite.
- Aucune deviation `MUST` ne peut rester implicite d'un sprint au suivant.
- Les decisions doivent etre referencees dans la conformance matrix.

## Livrables obligatoires

- Un rapport `spec-delta-Sx.md` en fin de chaque sprint.
