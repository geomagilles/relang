# Version tickets du plan S1-S10

Ce dossier fournit une version backlog exploitable immediatement.

## Fichiers

- `tickets-detailles.md`: specification execution-level ticket par ticket.
- `tickets.csv`: format tabulaire importable dans outil de suivi.

## Regles d'utilisation

1. Ne pas fermer un ticket sans ses tests d'acceptation.
2. Respecter l'ordre des dependances.
3. En fin de sprint, appliquer la gate governance:
   - spec-delta review,
   - conformance matrix,
   - risques ouverts.

## Prefixes

- `RL-Sx-YYY`: ticket du sprint `Sx`.
